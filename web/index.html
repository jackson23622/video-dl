浏览器登录信息

遇到 B站高画质、YouTube 人机验证、抖音等需要登录的内容时，直接借用本机浏览器里已登录的账号，不用导出 Cookies。选 Chrome / Edge / Brave 会弹出钥匙串授权，点“允许”即可；选 Safari 需要先在 系统设置 → 隐私与安全性 → 完全磁盘访问权限 里打开「视频下载器」。

登录 Cookies

一般用上面的“浏览器登录信息”就够了。浏览器读不到时，再手动粘贴 Netscape 格式的 cookies.txt（可用浏览器扩展 “Get cookies.txt LOCALLY” 导出）。只保存在这台电脑上。

关于

一个干净的本地视频下载器：没有广告，不追踪，只在这台电脑上运行。界面参考 cobalt，解析用 yt-dlp。文件直接存到「下载」文件夹。

怎么用

粘贴链接（整段分享文案也行）→ 按 »，会按“设置”里的画质和编码下载。想临时换画质，点“画质”手动选。播放列表和合集会弹出列表让你挑。

下载失败？

· 提示需要登录或人机验证：到设置里选“浏览器登录信息”。
· 平台刚改版：yt-dlp 每天自动更新一次，退出后重新打开即可。
· 海外网站连不上：需要电脑本身能访问这些网站（开着系统代理即可）。

　关闭页面后也会自动退出。
